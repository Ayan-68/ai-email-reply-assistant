# AI Email Reply Assistant

An AI-powered Streamlit application that generates professional customer support email replies using Google Gemini AI.

## Features

- Single message reply generation
- Bulk CSV reply generation
- Multiple reply tones
- Download generated replies
- Streamlit web interface

## Technologies Used

- Python
- Streamlit
- Google Gemini AI
- Pandas

## Installation

Install required packages:

```bash
pip install -r requirements.txt
```

## Run the App

```bash
streamlit run app.py
```

## CSV Format for Bulk Mode

Example:

```csv
customer_name,message
Ali,"I received a damaged product."
Sara,"My order is delayed."
```

- Professional replies

- Formal replies
- Apologetic replies
